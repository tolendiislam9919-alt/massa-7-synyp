# Масса және денелердің массасын өлшеу — 7-сынып

Интерактивті слайд-зертхана (физика, 7-сынып, «Тығыздық» бөлімі).
Мұғалім: Төленді И.Н., «Тайтөбе ауылының жалпы орта білім беретін мектебі» КММ.

## Ашу
- GitHub Pages қосылғаннан кейін: `https://<пайдаланушы>.github.io/<репозиторий>/`
- Компьютерде: `index.html` файлын браузерде ашу (`three.min.js` қасында тұруы керек).

## Басқару
- ← → немесе PageUp / PageDown — беттер
- F — толық экран, T — тақтаны жасыру/шығару
- `#N` — N-бетке тікелей өту (мысалы `.../#17`)

## Телефонмен қосылу
Толық нұсқау: `NUSQAULYQ.txt`. Тапсырма бетінде QR-ды үлкейткенде, слайдтың сол беті телефондарға ашылады.

## Файлдар
- `index.html` — сабақтың өзі; `?r=БӨЛМЕ` сілтемесімен ашылса, оқушы режимі
- `phone_panel.js` — мұғалім жағы: QR, тізім, нәтижелер
- `oqushy.js` — оқушы телефоны
- `net.js`, `mqtt.min.js`, `qrcode.min.js` — байланыс және QR
- `server.py`, `start.bat` — интернетсіз Wi-Fi роутер арқылы ашу үшін
- `three.min.js` — 3D кітапханасы (three.js r128)
- `.nojekyll` — GitHub Pages файлдарды өзгертпей беруі үшін
